## 使用约定

中文主稿是当前继续修改的入口，并不表示已经通过投稿前检查。英文长稿和部分图仍使用旧的效率记录；中英文稿存在统计表述差异。此次整理保留原文，未重写结论或重新编译 PDF。

最终效率证据以 `04_数据/01_最终指标/efficiency/efficiency_final_10x2.csv` 为准：CT-only 2.06±0.18 ms/slice，BridgeRefine 233.6±12.6 ms/slice。历史 `1017 ms`、`420×` 不应替代该协议的结果。

根据后续补充上传要求，手稿、常用图表、指标和说明纳入 GitHub 私有仓库的 `materials/`；影像、预测、权重、高分辨率图及其余材料完整收录于 [材料 Release](https://github.com/zaneWWWWWW/bridgerefine/releases/tag/materials-2026-09-17) 的独立 ZIP 分包。下载全部分包可恢复本地材料结构。仓库地址与记录见 [GitHub 发布记录](06_整理记录/GitHub发布记录.md)。

手稿内的 `figures/` 和定性病例入口采用相对符号链接，指向本整理包内的实际文件；整包移动时链接仍有效。单独复制手稿目录到 Windows 或其他机器时，需要同时复制对应图目录并命名为 `figures`。所有图像、数据和主要权重的实际文件均已收集在本包内。

如需校验副本：

```bash
python3 06_整理记录/verify_materials.py
```

原始目录和约 29 GB 的工程 ZIP 暂时保留。此任务没有删除旧包、虚拟环境或历史结果，因此不会释放它们占用的空间。
