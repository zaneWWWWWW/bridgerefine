# 数据与模型入口

本目录的指标和说明可在 GitHub 私有仓库中直接浏览；完整影像、预测缓存、模型权重及其余文件收录于同一仓库的 [材料 Release](https://github.com/zaneWWWWWW/bridgerefine/releases/tag/materials-2026-09-17)。下载全部 ZIP 分包可恢复此目录。

| 目录 | 内容及使用方式 |
|---|---|
| `01_最终指标/metrics` | v2 患者长表、配对差、seed 指标和原始显著性 JSON；162 行患者-方法记录 |
| `01_最终指标/efficiency` | 最终独立 10×2 效率测量：配置、原始计时、日志、汇总 |
| `02_原始结果表` | 投稿版与交接冻结版的 CSV/JSON 原件；按来源隔开，其中部分属于旧结果 |
| `03_逐实验记录` | 五组输入/seed 实验和效率记录；含配置、日志、切片/患者指标、预测、权重 |
| `04_影像数据/data_slices` | 原工程的 CT/MRI PNG 切片，保留全部文件；加载器按患者和切片名取配对交集 |
| `04_影像数据/brain` | 从原 ZIP 恢复的 180 组 CT、MRI、mask NIfTI，共 540 个 NIfTI 文件，另有原包附带预览和表格；这是包内影像版本，不代表未经处理的扫描仪原始数据 |
| `04_影像数据/patient_split.json` | 原患者划分文件：144/18/18 |
| `05_定性病例` | 高/中/低 SSIM 三名患者的数组、切片清单、预览和误差图 |
| `06_模型权重` | 按原工程相对路径放置的 10 份主要权重，另附 coarse-only 权重入口 |
| `07_预测缓存` | 10×2 测试 coarse 缓存和历史多模型预测；历史预测不应自动视为最终 10×2 结果 |

数据划分已按原加载器的文件名交集规则核对：

| 划分 | 患者数 | 配对切片数 |
|---|---:|---:|
| 训练 | 144 | 27,309 |
| 验证 | 18 | 3,473 |
| 测试 | 18 | 3,415 |

三组患者无交集。原数据有少量仅存在于单一模态的切片，已原样保留；这不等于配对样本缺失，实际加载器会取 CT/MRI 文件名交集。明细见 `../06_整理记录/数据划分核对.json`。

10 个主要 checkpoint 已与 v2 原始清单逐项哈希匹配，详见 `../06_整理记录/权重核对.csv`。特别注意，原工程 `checkpoints/selfrdb/selfrdb_best.pt` 的哈希与论文所列桥不同，本包恢复的是清单所指的 `other_model/SelfRDB/selfrdb_best.pt`。coarse-only 在这份 10 项主清单之外，其权重来自 v2 逐实验包，保留独立来源记录。

现有元数据仍不足以补齐伦理、知情同意、采集和配准信息，详见 `../05_说明与历史/元数据缺项/`。其中原始说明的“流程图缺失”已过时，当前已在投稿目录中找到 `BridgeRefine_pipeline_final.svg/.pdf`。
