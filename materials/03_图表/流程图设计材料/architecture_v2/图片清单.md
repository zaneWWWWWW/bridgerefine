## 需要从原始数组中优先导出的图片

如果 Figma 需要单独放置高分辨率影像缩略图，请从 `BridgeRefine_paper_handoff_v2/handoff_v2/qualitative_cases/` 的 `arrays.npz` 导出同一切片的：

```text
case_1_ct.png
case_1_mri_real.png
case_1_coarse_mri.png
case_1_bridgerefine_l1.png
case_1_ct_only.png
```

所有模型输出使用相同的 MRI 显示范围；不要单独锐化或增强 BridgeRefine 输出。扩散采样中间态当前没有 `states.npy/states.csv`，因此架构图中应使用明确标记的抽象采样 tile，而不是伪造医学图像。

## 图中必须出现的模块

1. Input CT
2. Frozen SelfRDB diffusion bridge
3. Coarse MRI representation
4. Channel concatenation
5. Supervised refiner
6. Synthetic MRI
7. Paired reference MRI
8. L1 reconstruction loss
9. Update refiner only

## 图中禁止出现的未实现模块

- Cross-attention
- Latent diffusion
- VGG/perceptual loss
- SSIM loss
- Anatomical constraint loss
- Discriminator in the main BridgeRefine path
- Transformer or ViT
- 3D continuity loss
- MRI replacement or diagnostic output
